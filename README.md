# T3 Approval Allowlist

这是一个 Chromium Manifest V3 扩展，只在 `https://t3.like.cloud` 上工作。

## 安装

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录。
5. 打开扩展的“选项”，粘贴审批卡片中的完整命令并加入白名单。
6. 刷新 T3 页面。

扩展只保存命令的 SHA-256 指纹。命令必须经过规范化后完全匹配，未匹配的命令不会点击批准。

0.4.0 起，白名单支持完整命令通配符，`*` 匹配任意字符，`?` 匹配一个字符。规则仍按整条规范化命令匹配。

0.3.0 起，扩展会监听 T3 后端 WebSocket 的会话更新，并在后端同步到审批详情时直接列出待审批命令。它不再只依赖左侧会话标签。

## 限制

- 默认白名单为空。
- 只识别审批卡片中名为“批准”或“Approve”的按钮。
- 仅匹配完整命令指纹，不支持模糊匹配、前缀匹配或自动批准全部。
- 变更命令、凭据、主机或参数后，需要重新加入白名单。
